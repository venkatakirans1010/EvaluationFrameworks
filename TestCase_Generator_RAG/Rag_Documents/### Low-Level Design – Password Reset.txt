### Low-Level Design – Password Reset

Steps:
1. User submits email -> generate JWT token -> send email link.
2. Reset link opens /reset?token=<jwt>.
3. Backend validates token and expiry.
4. On success, update user password (bcrypt).
5. Invalidate token and delete old sessions.

Test:
- Expired token -> 401 error
- Invalid email -> 404 user not found
- Valid token -> password updated successfully
